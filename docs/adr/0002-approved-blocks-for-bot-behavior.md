# Assemble bot behavior from approved blocks

Piko will represent bot behavior as flows assembled from developer-implemented, approved blocks rather than executing code generated by the builder agent. This limits what the future agent can make a bot do while supporting reusable templates; introducing a new capability requires implementing a block. Initial bots focus on buttons and data collection, with AI replies a possible later block, and the builder agent itself is outside this milestone.

Templates construct flows for one shared runtime rather than each having their own execution logic. A bot can combine several configured forms behind a menu, and owners initially configure menus and question blocks through ordinary settings rather than a visual block editor.

The Bot page provides an interactive Flow canvas in its own Flow tab for inspecting approved Blocks. The canvas defaults to the Draft and offers a separately labelled Published flow view. Compact graph nodes identify Block types with icons; selecting a node opens its details in an inspector. Main paths appear by default, secondary connections appear for the selected Block, and an explicit toggle exposes all connections. Preview remains in the Bot studio with a Test draft shortcut from Flow. The canvas does not offer direct graph editing; changes continue through the Builder agent or manual settings. This keeps inspection aligned with approved behavior while giving the owner room to understand the Bot's paths.

One simple, well-positioned Piko button in the Flow tab opens the most recent Builder chat for that Bot, or a new Bot-associated chat when none exists. It does not transfer the inspected Block into the composer or repeat change actions on Blocks. Node positions are automatic; owners navigate with pan, zoom, Fit, and a minimap rather than dragging nodes. A Draft update offers an explicit Refresh action instead of replacing the graph while it is being inspected; refresh retains selection when the Block still exists. Desktop uses a side inspector, while phones retain an interactive graph with touch pan and zoom and a bottom-sheet inspector. These choices preserve reading context and keep the Flow tab focused on understanding behavior.
